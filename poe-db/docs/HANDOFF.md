## 1. Пользователь и правила

- PoE 1 / 3.30 / Softcore, английский клиент. Игровые названия и моды — EN; общение и гайды — RU. Файлы, наборы и Notes в PoB — английский печатный ASCII; подробный RU-гайд — отдельно в UTF-8.

- Коммиты и push — только после подтверждения пользователя. `builds/main` меняется через CLI `build` с `--expected-revision`; неизвестные предпочтения остаются `null`. Данные старого RF-гайда не переносить в профиль как подтверждённые.
- Параллельные сессии в одной папке: перед сохранением каждого `.mjs` — `node --check`. Сломанный модуль роняет `agent.mjs` и все прогоны PoB в папке (так однажды сорвалась абляция корпуса).

## 3. Что умеет система (подробно — ENVIRONMENT.md)

- **Корпус (WP2):** `corpus discover poebuilds` → `corpus add-list` (возобновляемый) → `corpus ablate-all` → `learn` → `insights`; фильтр качества по умолчанию (level >= 80, есть восхождение, одна карточка на сигнатуру; `--all` его отключает). ## 5. Известные ограничения

- Числа PoB — не игровые тесты; игровых проверок (`observe`) пока нет. Механики вне PoB (recoup, взрывы, thorns, reflect) — `mechanically_valid` / low confidence.
- Прототипы WP5: дерево набирается жадно, предметы типовые. Локальные моды оружия экспортируются с 24.11.2026 (сессия B); сравнение атак и заклинаний после этого прогоном не перепроверено. `clear_score` — эвристика. Бюджет по ценам не проверяется (`profile.platform` = null, цен редких предметов нет).
- Новизна: веса проверены калибровкой (`corpus novelty --calibrate`): на 50 парах-вариантах из 22 архетипов подгонка не лучше априорных весов на отложенных архетипах, поэтому оставлены априорные + crit: 1. Crit берётся из кэша расчётов PoB (если кэша нет, ось не учитывается). Оси more-множителей нет: нет выгрузки модификаторов MORE по источникам.
- Корпус смещён к популярным гайдам с YouTube; популярность не доказывает эффективность.
- Скорость (24.11.2026): `agent.mjs` грузит модули команд лениво, пакетный пул анализа работает в worker-потоках — повторные `analyze report`/`ablate` ≈ 5 с вместо 15–21 с. Постоянные хосты PoB (`pob-pool.mjs`, включены по умолчанию, `POB_PERSISTENT=0` — старый путь): первый расчёт ≈ 7 с на загрузку хоста, следующие ≈ 0.1–1 с; при сбое хоста расчёт уходит на однократный процесс с предупреждением. Контракт сменился — кэш расчётов пересчитывается. Подробно — ENVIRONMENT.md, «Производительность команд».
- Ограничения источников: poe.ninja — только economy API; Maxroll, YouTube и форум автоматически не собирать; ладдер GGG публичен, но предметы персонажей — только через OAuth-приложение, которое регистрирует пользователь.
